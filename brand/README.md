# Identidade visual · Ninho Monitor

O símbolo representa um ninho abstrato: duas curvas de acolhimento envolvendo um ponto central. Ele substitui o desenho de câmera da marca anterior. A versão final foi construída em SVG a partir do conceito visual gerado; não é um rastreamento pixel a pixel do raster.

- `ninho-symbol.svg`: símbolo para fundo escuro.
- `ninho-symbol-ink.svg`: símbolo para fundo claro.
- `ninho-logo-dark.svg`: assinatura clara, com texto convertido em curvas, para fundo escuro.
- `ninho-logo-light.svg`: assinatura escura para fundo claro.
- `ninho-icon.svg`: ícone quadrado do aplicativo/PWA.
- `brand-preview.svg`: prancha de apresentação.

A tipografia de interface é Manrope, usada somente nos pesos 400 e 600. A fonte é distribuída sob SIL OFL 1.1; veja Manrope-OFL.txt. As assinaturas vetoriais já têm os caracteres convertidos em curvas.

Paleta: floresta `#101B1C`, superfícies `#172526` / `#1C2C2D`, texto `#F2F7F5`, secundário `#B8C9C6`, menta `#77E2C2` e tinta de botão `#09221B`. A versão para fundo claro usa `#0E5743` no símbolo. Não aplicar a assinatura clara sobre branco.

Manter área livre equivalente a pelo menos metade do diâmetro do ponto central. Não esticar, girar, acrescentar sombras ou converter o símbolo em olho/câmera. Na interface, o ícone da câmera continua permitido para representar a função de vídeo; ele não deve ser usado como logotipo.
